# Security Policy

## Supported Versions

Security fixes are provided for the latest released Infbyte version.

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting
for this repository. If it is unavailable, contact maintainers through a
private channel. Do not open public issues for suspected vulnerabilities.

Include the affected version, PHP/runtime details, reproduction steps or proof
of concept, impact assessment, and any known workaround.

## Automated Gates

Infbyte uses PHPForge for tests, static and security analysis, dependency
auditing, architecture checks, and release-readiness verification locally and
in CI.
