# Infbyte

Infbyte is a lightweight PHP application skeleton powered by [Foundation](https://github.com/infocyph/Foundation).

## Installation

Requires PHP 8.4 or newer and Composer 2.

```bash
composer create-project infocyph/infbyte my-app
cd my-app
php infbyte serve
```

Infbyte 4 uses Foundation `^4.0`. For production deployment and optional features, see the documentation.

## Documentation

See the [Infbyte framework manual](https://github.com/infocyph/Foundation/blob/main/docs/index.rst).
